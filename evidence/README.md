## Interpretation and Limitations

- These images are point-in-time evidence; they do not establish that every resource remains in the same state today.
- The Application Load Balancer and target group were tested and then deleted. They should not be presented as currently deployed.
- No RDS database instance or NAT Gateway was launched.
- Budget alerts provide notification, not a hard spending cap.
- Review screenshots for account identifiers, IP addresses, and billing details before sharing this public repository.
